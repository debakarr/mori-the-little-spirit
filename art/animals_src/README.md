# Wildlife (source)

Deer and stag from Quaternius' **Ultimate Animated Animal Pack** (CC0 1.0, `License.txt`), glTF versions from the
pack's Google Drive (linked from https://quaternius.com/packs/ultimateanimatedanimals.html).
`node tools/prepare_animals.mjs` writes `public/models/deer.glb` and `stag.glb` with only the gentle clips.
